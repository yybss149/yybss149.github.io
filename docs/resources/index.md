## 如何管理

运行本文件夹中的 `resource_manager.py` 后，在浏览器打开资源库管理器。只要输入网址和备注，就能添加或删除资源，内容会自动保存到本页；点击“同步到网站”即可自动发布到线上网站。

你也可以直接编辑本文件；请保留上方的 `RESOURCE_MANAGER_START` 和 `RESOURCE_MANAGER_END` 两行标记，管理器才能正常工作。

```markdown
- [我推荐的工具](my-tool.md)：我的使用心得。
```
